# NavaTunnel

[English](README.md) · [راهنمای استفاده](docs/USAGE.fa.md) · [بکاپ و نگهداری](docs/OPERATIONS.fa.md)

مدیریت تونل GRE و اتصال معکوس FRP از طریق منوی انگلیسی ترمینال. اسکریپت روی ایران و خارج اجرا می‌شود و اینباندهای برنامه روی خارج باقی می‌مانند.

```text
Users → Iran service ports → FRP over GRE/FOU → Foreign application
```

## نصب

روی هر دو سرور با کاربر root اجرا کن:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/admin6501/NavaTunnel/main/install.sh)
```

برای بازکردن منو در دفعات بعد:

```bash
NavaTunnel
```

سرور باید لینوکس با systemd و دسترسی root داشته باشد؛ Ubuntu 22.04/24.04 و Debian دارای systemd مناسب‌اند. دانلود وابستگی‌ها و هسته FRP به اینترنت نیاز دارد. کرنل و شبکه دیتاسنتر باید روش GRE یا FOU انتخاب‌شده را پشتیبانی کنند. فایروال سیستم‌عامل و دیتاسنتر نیز باید ترافیک لازم را عبور بدهند.

## ساخت اولین تونل

1. روی **ایران** وارد **۱ ← ۱، Create tunnel on Iran** شو.
2. نام تونل، IP عمومی دو سرور و پورت‌های اینباندهای موجود روی خارج، مثلاً `443,8443` را وارد کن.
3. برای شروع با TCP، جبران افت بسته را خاموش بگذار. پورت کنترل آزاد وارد کن یا برای انتخاب خودکار Enter بزن.
4. بعد از ساخت، وارد **۱ ← ۳** شو، تونل را انتخاب کن و **گزینه ۸، Get foreign connection code** را بزن.
5. روی **همان سرور خارج**، NavaTunnel را نصب کن و فقط دستور اتصال نمایش‌داده‌شده را اجرا کن.
6. بعد از موفقیت نصب، اتصال برنامه را با آدرس ایران امتحان کن.

کد اتصال شامل توکن محرمانه است. آن را عمومی منتشر نکن. اسکریپت پورت‌های برنامه موجود را فوروارد می‌کند؛ اینباند و کاربر برنامه ایجاد نمی‌کند.

## منوی اصلی

| گزینه | کاربرد |
| --- | --- |
| ۱ | ساخت و مدیریت تونل‌ها و تغییر IP عمومی ایران |
| ۲ | تنظیم شبکه، GRE/FOU، محدودیت SYN، ترافیک پوششی، واچ‌داگ و تنظیمات FRP |
| ۳ | بررسی سلامت، لاگ، بکاپ رمزگذاری‌شده، ریستور و انتقال با SSH |
| ۴ | به‌روزرسانی، دریافت هسته FRP و نمایش تنظیمات سیستم |
| ۵ | حذف نصب |
| ۶ | مصرف ترافیک، نحوه محاسبه، سقف و ریست |

روی ایران، **۱ ← ۳** صفحه مدیریت تونل انتخاب‌شده را باز می‌کند: شروع، توقف، ری‌استارت، پورت سرویس، نام، IP خارج، روش GRE، کد اتصال، ترافیک، جبران افت، پروتکل FRP، MTU، پورت کنترل و توکن. می‌توان چند خارج را روی ایران ثبت کرد؛ پورت‌های سرویس عمومی آن‌ها روی ایران نباید تکراری باشند. نصب استاندارد خارج، یک اتصال GRE/FRPC را روی هر سرور خارج مدیریت می‌کند.

## ترافیک

واحد مصرف و سقف **GB ده‌دهی** است؛ هر GB برابر یک میلیارد بایت است. دانلود یعنی دریافت توسط همان سروری که شمارنده روی آن اجرا می‌شود و آپلود یعنی ارسال آن. محاسبه سقف می‌تواند دانلود، آپلود یا هر دو باشد. شمارنده عادی GRE فقط ترافیک IPv4 داخل تونل را می‌شمارد؛ بنابراین با مصرف دیتاسنتر یکسان نیست. پایش هر ۱۰ ثانیه انجام می‌شود.

## به‌روزرسانی

روی ایران و همه سرورهای خارج اجرا کن:

```bash
NavaTunnel update-all
NavaTunnel
```

اگر قبلاً از قابلیت‌های اختیاری نسخه‌های قدیمی استفاده کرده‌ای، [راهنمای ارتقا](docs/OPERATIONS.fa.md#ارتقا-از-نسخههای-قدیمی) را بخوان. تنظیمات و آمار تونل‌های معمولی GRE/FRP در پاک‌سازی حفظ می‌شوند.
