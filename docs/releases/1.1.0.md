NavaTunnel 1.1.0 brings the original upstream networking backend into a standalone terminal-managed core. No browser administration panel or Backhaul engine is included.

## Added

- Original Cluster foreign exit pool and Iran mesh, with weighted routing, failover and lowest-latency selection.
- WSS carrier for GRE and an FRP WSS TLS front.
- Connectivity Rescue, reverse-path diagnosis and explicit repair, linked benchmarks and opt-in Auto Pilot.
- Adaptive FRP Auto Pool, manual capacity, GRE/public dial-route controls and RAM-scaled tuning.
- Fleet/link history, seven-day traffic history, authenticated peer linking, optional alerts and bearer-protected metrics.
- An explicit TCP-only Direct SSH mode in NavaLink, alongside FRP TCP/UDP over SSH.

Open **Advanced settings (2) → Standalone upstream tools (11)**. Existing tunnels remain configured. Routing and automatic switching are not enabled by updating. Cluster forwards traffic; it does not replicate users/inbounds or create missing endpoint tunnels.

## Install / update

Run as root on Iran and each foreign endpoint:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/admin6501/NavaTunnel/main/install.sh)
```

For an existing installation:

```bash
NavaTunnel update-all
NavaTunnel
```

The optional core is downloaded and SHA256 checked when first requested. No Go installation is needed on servers. Release assets support Linux amd64, arm64, armv7 and 386. `checksums.txt` covers the four executable assets; the script selects the matching architecture automatically.

## Fixes and verification

Firewall changes use dedicated chains, scoped connection marks and rollback. Unrelated rules and existing traffic quotas are preserved. Failed carrier/restart operations report errors; WSS counters are synchronized. Transport changes handle WSS/QUIC control-port offsets. Core state and peer certificate identity are included in encrypted backups.

Validation: 225 Python regression/menu tests, 133 Go tests with the race detector, adapted upstream Auto Pool/dial tests, Bash/ShellCheck error checks, real isolated Cluster TCP/UDP failover and weighted routing, WSS datagram/authentication tests, and privileged SSH authorization/data-path labs. All GitHub CI jobs passed on the tagged source. Provider-specific networking still needs testing on your endpoints.
