This update keeps **Cluster and NavaLink** and removes the other optional tools introduced in 1.1.0.

## Retained

- Original Cluster foreign exit pool, weighted routing, failover, lowest-latency selection and Iran mesh.
- NavaLink FRP over SSH and explicit TCP-only Direct SSH, including setup, conversion, rollback, quotas and key restrictions.
- Existing GRE/FRP management, FRP protocols, traffic limits and reset, persistent MTU, backup/restore, migration and the original shell maintenance controls.

The optional menus are now **Advanced (2) → NavaLink (9)** and **Advanced (2) → Cluster (10)**.

## Removed

The multi-tool menu, GRE WSS relay, Rescue, Auto Pool, reverse-path doctor, benchmark/Auto Pilot, history and reports, metrics, standalone alerts, Peer Link, dial-route helpers and separate network-tools page have been removed from the code, CLI and runtime. The WebSocket library is no longer a dependency of this core.

The retained core handles Cluster, its private control socket, authenticated TLS heartbeats and the TLS front required by the existing FRP WSS protocol. It does not run the removed collectors or expose their APIs.

## Upgrade

On Iran and each foreign endpoint:

```bash
NavaTunnel update-all
NavaTunnel
```

The second command loads the new menu and runs the retirement migration. Removed settings are privately archived under `/var/backups/navatunnel/removed-tools-*`; their owned services and Rescue nftables tables are retired. Cluster/NavaLink records, main FRP files and quota counters are preserved. Existing FRP pools and addresses are not automatically retuned or all restarted by the script update.

An already-installed core is upgraded with checksum verification and daemon version checks. A failed core restart restores the previous executable and reports failure. An active removed GRE WSS relay is moved to the existing FOU carrier; update both endpoints when retiring that relay. FRP WSS itself remains supported.

Fresh install:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/admin6501/NavaTunnel/main/install.sh)
```

Release assets support Linux amd64, arm64, armv7 and 386, with `checksums.txt`. Source and AGPL attribution are retained.

Validation includes Python regression/menu/restore/migration tests, race-enabled Go Cluster tests, real isolated TCP/UDP exit failover and weighted forwarding, TLS heartbeat authentication, owned-resource retirement with unrelated firewall preservation, and the SSH TCP/UDP/direct-forwarding authorization lab.
